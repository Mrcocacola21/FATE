# Друзья, онлайн-статус и приглашения в лобби — план

Макеты: [артефакт «Друзья и приглашения FATE»](https://claude.ai/artifact/Sgo7vi1m1WbM3QH8D3DBTg) — 7 экранов в стиле «Гримуара».

## Принятые решения

- **Дружба взаимная**: заявка → «Принять» / «Отклонить». Удалить можно в любой момент.
- **Звать в лобби можно любого игрока**, если он не запретил это в настройках («Все / Только друзья / Никто»). Лимит — 10 приглашений в минуту от одного игрока. Приглашение живёт 2 минуты или пока место не займут.
- **Уведомления**: колокольчик в шапке и всплывашка справа снизу, приходят сразу через уже открытый WebSocket. В бою приглашения не всплывают, а копятся в колокольчике.
- **Онлайн-статус**: «в сети», «в лобби», «в бою» или «был в сети N назад». «В сети» видят все, подробности (какое лобби, какой бой) — только друзья. Можно скрыть статус совсем.
- **Блокировка**: убирает дружбу, запрещает заблокированному слать заявки и приглашения, прячет его из поиска.

## Что есть в коде сейчас

- Лобби живут только в памяти (`packages/server/src/store.ts`, `games`), все публичные; войти можно по id комнаты.
- Один WebSocket на пользователя открыт по всему сайту через подписку на матчмейкинг (`MatchmakingSync`), но общего канала событий пользователя нет.
- Нет таблиц дружбы и блокировок, нет поиска игроков, нет уведомлений и онлайн-статуса.

## Этапы

### 1. Друзья и поиск
- [x] Таблицы `Friendship` (заявка или дружба, одна строка на пару) и `UserBlock`; настройка «кто может присылать заявки» в профиле.
- [x] API: список друзей, входящие и исходящие заявки, отправить / принять / отклонить / отменить, удалить из друзей, заблокировать / разблокировать, поиск игрока по началу ника, отношение к конкретному игроку.
- [x] Веб: страница «Друзья» (вкладки «Друзья», «Заявки», «Найти игрока»), пункт в сайдбаре со счётчиком входящих заявок, кнопки дружбы в публичном профиле.

### 2. Онлайн-статус
- [x] Учёт соединений по пользователю на сервере, статус «в лобби / в бою» из комнат.
- [x] «Был в сети» (сохраняется при выходе), настройка видимости статуса.
- [x] Статусы в списке друзей и в шапке профиля. Закрывает пункт «Онлайн-статус» из плана профиля.

### 3. Уведомления
- [x] Канал событий пользователя в WebSocket (не только для матчмейкинга). Сервер шлёт `notification`, `friendsChanged` и `presence` во все сокеты игрока (`AccountConnections.send`); веб принимает их только для аккаунта, с которым подписан сокет.
- [x] Колокольчик со списком и всплывашки: новая заявка, заявка принята. Таблица `Notification` (миграция `20261030090000_notifications`) висит на строке дружбы, поэтому отменённая заявка, удалённый друг или блокировка убирают и уведомление. `GET /api/notifications`, `POST /api/notifications/read`. Колокольчик в сайдбаре и мобильной шапке, заявку можно принять прямо из него или из всплывашки. В бою всплывашки не показываются, уведомления копятся в колокольчике.
- [x] Живые статусы друзей: сервер раз в 2 секунды и сразу при подключении/отключении сравнивает статусы игроков в сети и рассылает изменения их друзьям; страница «Друзья» обновляется без перезагрузки.

### 4. Приглашения в лобби
- [x] Приглашения в памяти сервера рядом с комнатами (`invites/inviteService.ts`), таймер 2 минуты, лимит 10 новых в минуту, настройка «кто может меня звать» (`Profile.lobbyInvites`, миграция `20261031090000_lobby_invites`). Звать можно только из своего обычного лобби, пока второе место свободно; приглашение пропадает, когда место заняли, пригласивший ушёл или игра началась. API: `POST /api/lobbies/:roomId/invites`, `GET /api/invites`, `DELETE /api/invites/:id`; по сокету — `invite` и `inviteGone`.
- [x] Панель «Пригласить игрока» в комнате ожидания (друзья, свободные сверху, и поиск по нику), всплывашка и колокольчик с «Войти в лобби» (сразу садит на свободное место) и таймером, кнопка «Позвать в лобби» у друзей и в профиле. Закрывает пункт «Приглашение в лобби» из плана профиля.
