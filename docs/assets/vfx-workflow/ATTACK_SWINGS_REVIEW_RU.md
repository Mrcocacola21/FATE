# Проверка подключённых взмахов — v10

Охват: 27 expansion PNG с geometry=swing — 24 обычных взмаха и три действия форм (Guts Berserk, Kaneki Centipede, Undyne Undying). Снаряды и прежние уникальные сцены KEEP сохраняют свои маршруты.

Обнаружено:

- Реальный одиночный удар Guts Berserk не имел isBasicAttack, поэтому его berserk_swing не достигался из настоящего действия правил. Прежний тест формы использовал искусственный базовый результат. Добавлена точная подпись attackSignature=gutsBerserkSingle после принятого выбора single. Она проходит через существующие проекции. Флаг isBasicAttack не добавлен: нынешний SFX-маршрут, механика, расход и RNG сохранены. AoE не получает эту подпись.
- Нижний предел 100 мс продлевал expansion release за конец 70-миллисекундного окна reduced motion. Теперь release заканчивается на общем outcome-clock: 210 мс в обычном режиме, 70 мс в reduced motion. Попадание остаётся отдельной фазой только на подтверждённом hit.
- Взмах был центрирован на портрете. Только для geometry=swing рамка увеличена до 1,45 клетки, pivot перенесён в 15% ширины. Точка вращения остаётся в разрешённой клетке атакующего, оружие выступает в направлении цели. PNG не изменены.

Проверено: 336 effects-тестов, 66 SFX-тестов, полный rules (3 набора), сетевые контракты (20 наборов), asset audit, root lint/typecheck/build и свежая production-проверка 327 определений. `vfx-expansion-game-smoke.mjs --swings-only --phone-motion --dark` выполнил 261 сценарий: 27 PNG и два дополнительных направления Guts, P1/P2/spectator, desktop, animated phone, phone/reduced motion. Проверяются настоящий rules-маршрут, один release, pivot и направление, окно 210/70 мс, отсутствие раннего impact, повтор, очистка и reconnect.

Все 27 PNG просмотрены в середине release на реальном Board desktop/phone; дополнительно просмотрены вертикаль/диагональ Guts. Для снимков CSS-анимации останавливаются на общей фазе. У Chromium обнаружено устаревшее изображение слоя при headless seek задержанного strip: в инструменте съёмки снимается только will-change hint, без изменения геометрии, кадра, opacity и времени. Отдельно проверено появление Guts на настоящих часах без этого изменения; артефакт относился к снимкам. Производственный CSS ради теста не менялся.

Кадры: `packages/web/test-results/vfx-expansion-game/swing-contact-sheets/`; 4 desktop и 4 phone листа, 29 сцен на каждый размер. Результат: `swings-report.json`, проверки: `swing-*.log`. Полная ручная анимационная/сетевая QA и прежние три механических блокера пака остаются отдельным остатком; этот просмотр не ставит fullRuntimeQa=true.
