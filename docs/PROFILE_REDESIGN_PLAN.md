# Редизайн профиля — план

Макеты: холст в [артефакте](https://claude.ai/artifact/Kjut9uRDPn1Tdc38Re4ugT), ряд «Профиль — новая версия» (свой, публичный, мобильный).
Макеты рисовались до стиля «Гримуара» — при реализации переводить в него: арка аватара, капители, Alegreya, золотые уголки только на главных элементах (см. `packages/web/src/components/grimoire.tsx`).

## Состав экранов

### Свой профиль
- Шапка: аватар (сменить), ник, ранг, «в FATE с …», «был в сети», «О себе» до 160 символов. Кнопки «Редактировать профиль», «Поделиться», «Как видят другие».
- Три карточки рангов (Стандарт, Драфт, Классика): рейтинг, место в таблице лидеров, сколько до следующего ранга, калибровка.
- График рейтинга с переключателем форматов.
- 6 плиток статистики: матчи, процент побед, серия, длительность и т.п.
- «Герои»: игры и процент побед по каждому герою.
- «Последние матчи»: результат, соперник, формат, длительность, мини-отряд, изменение рейтинга, «Реплей».
- «Видно только вам»: почта, язык, тема, настройки аккаунта.

### Публичный профиль
- То же без приватного блока.
- Кнопки «Позвать в лобби», «История матчей», «Поделиться».
- «Вы против X — 3:2» (личные встречи).
- «Текущий отряд» с «Скопировать себе».

### Мобильная версия
Компактная шапка, карточка ранга с вкладками форматов и графиком, 4 плитки, 3 последних матча.

## Что есть в коде сейчас

Web:
- `packages/web/src/pages/ProfilePage.tsx`, `pages/PublicProfilePage.tsx`
- `packages/web/src/profile/` — `Avatar`, `ProfileForm`, `ProfileRank`, стор профиля
- `packages/web/src/statistics/` — `PlayerStatisticsSection`, `StatisticsSummary`, `GameModeBreakdown`, `RecentPerformance`, `useProfileResource`
- `packages/web/src/matches/` — список истории матчей, фильтры, бейдж типа матча

Server (`packages/server/src/routes/`):
- `GET/PATCH /profile`, `GET /users/:username` — профиль
- `GET /users/:id/rating`, `GET /users/:id/ratings` — ранги по форматам
- `GET /users/:id/rating/history` — история рейтинга (**web пока не использует** — основа графика)
- `GET /users/:id/statistics` — статистика в целом, по форматам, серии, длительность
- `GET /leaderboard` — отдаёт `ratingRank` по режиму; проверить, хватит ли его для «места в таблице» без отдельного эндпоинта
